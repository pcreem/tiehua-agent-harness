# Format: Structured Text Output Guardrail

## 輸出格式要求
適用於不支援 Markdown/JSON 的介面（LINE、SMS、語音助理），使用**純文字結構化格式**。

## 結構規範

### 區塊分隔符
```
=== 區塊標題 ===
內容...
```

### 必須區塊（依序）

#### 1. 標題區塊
```
=== 台東旅遊建議 ===
```

#### 2. 摘要區塊
```
=== 摘要 ===
台東今天多雲 26°C，降雨機率 30%。建議上午安排戶外，午後備選室內景點。
```

#### 3. 天氣資訊
```
=== 天氣資訊 ===
溫度：26°C
天氣：多雲
降雨機率：30%
資料來源：Open-Meteo（更新：2024-01-15 10:00）
```

#### 4. 推薦清單（使用編號+縮排）
```
=== 景點推薦 ===
[戶外・建議上午]
1. 三仙台 — 著名跨海橋、海蝕地形
2. 都歷部落 — 阿美族文化、海景咖啡廳

[室內・備選午後]
1. 鐵花村 — 原創音樂、市集、文創
2. 台東美術館 — 當代藝術、親子友善
```

#### 5. 住宿建議（表格式對齊）
```
=== 住宿推薦 ===
蘭舍民宿     民宿   近鐵花村・手沖咖啡    NT$2,500-3,500
某某飯店     旅館   近火車站・CP值高      NT$1,800-2,500
```

#### 6. 行動清單（可勾選）
```
=== 行動建議 ===
☐ 攜帶輕便雨具（午後可能有陣雨）
☐ 提前預訂住宿（旺季房源緊俏）
☐ 租機車最方便（大眾運輸較不便）
```

#### 7. 後續服務
```
=== 後續服務 ===
需要我協助什麼？
- 查詢大眾運輸時刻表
- 規劃 2 天 1 夜詳細行程
- 推薦適合親子/長輩的景點
```

## 格式規範
- 區塊標題：`=== 標題 ===`（左右各 3 個 `=`）
- 縮排：使用 2 空白或全形空白
- 分隔：區塊間空一行
- 關鍵值：`鍵：值` 格式（全形冒號）
- 列表：數字編號 `1.` `2.` 或 `☐` `✓`
- 表格：欄位用全形空白對齊，不使用 `|`
- 長度：單一回覆建議 500 字以內（語音/簡訊限制）

## 禁止事項
- 不要使用 Markdown 語法（`#` `*` `-` `|` `>`）
- 不要使用 JSON 格式
- 不要輸出超過 3 個區塊的空白行
