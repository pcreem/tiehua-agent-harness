# Format: Markdown Output Guardrail

## 輸出格式要求
所有回覆使用 **Markdown** 格式，遵循以下結構規範：

## 必須包含區塊（依序）

### 1. 標題
```markdown
# 台東旅遊建議
```
- 使用一級標題 `#`，內容為回覆主題

### 2. 摘要
```markdown
> **摘要**：台東今天多雲 26°C，適合安排上午戶外、午後室內行程。
```
- 使用引用區塊 `>` 加粗標籤 `**摘要**`
- 一段話，100 字以內

### 3. 詳細內容
```markdown
## 天氣資訊
- **溫度**：26°C
- **天氣**：多雲
- **降雨機率**：30%
- **資料來源**：Open-Meteo（更新：2024-01-15 10:00）

## 景點推薦
### 戶外景點（建議上午）
1. **三仙台** — 著名跨海橋、海蝕地形觀賞
2. **都歷部落** — 阿美族文化、海景咖啡廳

### 室內景點（備選午後）
1. **鐵花村** — 原創音樂、市集、文創
2. **台東美術館** — 當代藝術、親子友善
```

### 4. 住宿建議（如適用）
```markdown
## 住宿推薦
| 名稱 | 類型 | 特色 | 價位參考 |
|------|------|------|----------|
| 蘭舍民宿 | 民宿 | 近鐵花村、手沖咖啡 | NT$2,500-3,500/晚 |
| 某某飯店 | 商務旅館 | 近火車站、CP值高 | NT$1,800-2,500/晚 |
```

### 5. 行動建議
```markdown
## 💡 行動建議
- [ ] 攜帶輕便雨具（午後可能有陣雨）
- [ ] 提前預訂住宿（旺季房源緊俏）
- [ ] 租機車最方便（大眾運輸較不便）
```

### 6. 後續詢問
```markdown
---
**需要進一步協助？**
- 查詢大眾運輸時刻表
- 規劃 2 天 1 夜詳細行程
- 推薦適合親子/長輩的景點
```

## 格式規範
- 標題層級：`#` → `##` → `###`（不跳級）
- 列表：使用 `- ` 或 `1. `，保持一致
- 表格：使用 `|` 分隔，標題列加粗
- 重點：使用 `**粗體**`、`~~刪除線~~`（極少用）
- 表情符號：僅在區塊標題前使用（如 `## 💡`），內文避免

## 禁止事項
- 不要輸出純文字無結構段落
- 不要使用 HTML 標籤
- 不要在表格外使用 `|` 分隔
